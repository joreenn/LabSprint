Source checking and agent cross-checks are **not independent review by an MLS faculty member or medical professional**. Qualified editorial review is still needed.

## Reference mixing and integrity

- New session selection mixes eligible subjects and then available reference editions within each subject without replacement. Question style/topic/explicit-ID filters remain binding. A short session cannot guarantee every source and a topic may have only one source.
- The source shelf reports the actual available count, target, remaining count, and number of reference editions for each subject. The target is not shown as an achieved count.
- All 56 original items are preserved unchanged, including keys, versions and source metadata. Existing history, accounts, bookmarks and saved sessions are not migrated or cleared. Current-bank coverage naturally uses the larger denominator.
- Validation additionally rejects normalized duplicate stems and duplicate choice text. This catches exact count padding, not semantic duplication or incorrect facts. Future batches require editorial review of objectives and coverage, not simply passing structural tests.
